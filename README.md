# Audio Source Inspector

Tampermonkey/Violentmonkey userscript that captures audio sources on a page and lets you download them with track-based file names ("Artist - Track Title.mp3").

## Install
1. Install Tampermonkey or Violentmonkey.
2. Open `audio-inspector.user.js` and install it.

## Features
- Captures `<audio>`/`<source>` URLs, `play()` calls, and audio requests (fetch/XHR).
- Names files as "Artist - Track Title.mp3" when track info is detected.
- Optional auto-download.
